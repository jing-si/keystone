# 작업 계층 정의

## G01 - 선택적 Work·Task와 실행·복구 경계

### Q01 - Task 기록·복구 수준

- 질문: Task는 별도 상태·수락 단위로 만들지 않고, 재개에 필요한 항목만 기존 Step 기록에 남겨 AI가 관리하는 방식으로 할까요? 대안은 모든 생성 Task에 고유 식별자·상태를 두고 지속 추적하는 방식입니다.
- 답변: 1 — Step 안에서 필요한 만큼 기록. 재개에 필요한 항목만 남기고 AI가 관리하며 Task별 독립 상태·수락 절차는 두지 않는다.

### Q02 - Work의 문서 분리 기준

- 질문: Work는 기본적으로 Round 작업서 안에서 구분하고, 내용이 크거나 별도 관리가 필요할 때만 파일을 분리할까요? 대안은 Work를 만들 때마다 별도 작업서를 만드는 방식입니다.
- 답변: 1 — 기본은 Round 작업서 안에서 Work를 구분하고, 내용이 크거나 별도 관리가 필요할 때만 파일을 분리한다.
